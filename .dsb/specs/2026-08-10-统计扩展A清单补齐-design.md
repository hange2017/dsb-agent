## A5:压缩质量抽查(compaction_qa)

### 触发时机

agentLoop 主循环自动压缩成功时触发(compact 返回后);手动 compactNow 不触发。

### 数据流

1. `contextManager.compact()` 带出被压缩掉的 `compactedSeqs: number[]`(旧消息对应 seq,取前几个)
2. agentLoop(有 provider.round 访问权)执行 QA:
   - 取 compactedSeqs 中随机 2 个序号
   - 独立 provider.round 调用,单条 user 消息:压缩块全文 + 问题
     「`[r42]` 对应的原始内容是什么?只回简要结论,1-2 句话,不确定回 UNKNOWN」
   - maxTokens ~200,tools: []
3. 判定:返回包含具体信息(非 UNKNOWN、非空)→ answerable: true;否则 false
4. 落盘新事件:

```ts
{ t: epoch_ms, type: "compaction_qa",
  data: {
    sessionId: string;
    seq: number;           // 抽查的 [r{n}]
    answerable: boolean;
    qaMs: number;          // QA 调用耗时
    qaInputTokens: number; // QA 自身输入(压缩块全文)
    qaOutputTokens: number; // QA 自身输出
    inTokens: number; outTokens: number;  // 该次压缩 before/after
  }}
```

### Token 扣减(用户强调)

- QA 调用走独立 provider.round,**不进 onProviderRound**(不污染对话轮次统计)
- QA token 只记在 compaction_qa 事件自身
- `hourlyCostSummary()` 把 QA token 单列一行:「QA 抽查成本」独立显示,`realCost = costTotal - qaCost`
- 每次 QA 成本 ≈ ¥0.017(17K 输入 × ¥1/M),一天 ≈ ¥0.22,可忽略

### 开关

`detailLevel=full` 才触发(默认 full);basic 跳过;enabled=false 全关。

## 聚合侧(src/stats/aggregate.ts 新增,纯函数)

### A3 `analyzeCacheAfterCompact(events, opts)`

```ts
{ compactions: Array<{
    startedAt: number;            // 压缩开始
    beforeMissRate: number;       // 压缩前 5 轮平均 miss 率
    firstMissRate: number;        // 压缩后第 1 轮 miss 率(雪崩峰值)
    extraMissTokens: number;      // 相对基线多出的 miss token(雪崩量)
    recoveryRounds: number;       // 恢复到 beforeMissRate 需要的轮数
  }>,
  totalExtraMissTokens: number;
  avgRecoveryRounds: number;
}
```

口径:miss 率 = `(inputTokens - cacheReadTokens) / inputTokens`;基线 = 压缩前 5 轮中位数;
雪崩量 = 压缩后每轮 `(missRate - 基线)× inputTokens` 正值累加,连续 3 轮低于基线视为恢复。

### A4 `hourlyCostSummary(events, prices)`

```ts
{ hours: Array<{
    hour: "2026-08-10T18:00";       // 本地小时
    rounds: number; compactions: number;
    inputHit: number; inputMiss: number; output: number;
    costHit: number; costMiss: number; costOutput: number;
    costTotal: number;
    qaInput: number; qaOutput: number; qaCost: number;  // QA 单列
    realCost: number;               // costTotal - qaCost
  }> }
```

单价默认:`hit ¥0.02/M, miss ¥1/M, output ¥2/M`,可参数覆盖(D2 官方单价校准)。

### A6 `sessionRoundAgg(events)`

```ts
{ rounds: Array<{
    roundIndex: number;            // 会话内轮次
    ok: boolean;                   // 该轮无 error = 成功
    roundsSinceCompaction: number; // 距离上次压缩的轮数(-1 = 压缩前)
    windowTokens: number;          // 该轮生效的窗口
  }>,
  agg: Array<{ windowTokens: number; compressCount: number; roundsAnalyzed: number; successRate: number }>
}
```

轮次边界:每次用户发送 → agent 完成(phase=chat 的 provider_round 计数);
error 判定:该轮内 `{type:"error"}` 终态(取消不计失败)。
