## 四、回来时建议的分析维度(占位,实施时按需细化)

- **规模**:跨了多少项目 / 多少会话 / 多少 round / 多少 tool 调用。
- **效率**:每轮任务的平均 round 数与工具调用数;是否存在"一个消息炸出几十个子任务"。
- **重复工作**:`tool_repeat` 埋点(重复调用同一工具同参数)占比 —— 直接对应历史上
  「输出被极端裁剪 → agent 重复劳动」这一担心。
- **信息丢失代价**:因 tool_result 裁剪/压缩导致的重试、回溯、重新读取文件的次数。
- **缓存**:稳定期命中率(基线 97.0~97.7%)、压缩后首轮(基线 49~54%);
  用 `scripts/analyze-cache-prefix.py` 对比。
- **失败模式**:工具调用报错率、REFUSED(瞬时标记拦截)、ROLLED BACK、上下文溢出等。
