# 04 · 健康度 / 技术债清单

> 状态:📄 骨架(待填充)
> 前置:建议先完成 [01-architecture.md](01-architecture.md) 与部分 [03-module-deepdives/](03-module-deepdives/) 后填充。

## 目的

逐模块评估健康度(职责清晰度 / 耦合度 / 测试覆盖 / 技术债),形成待办式清单,方便后续逐个清理。

## 待分析问题(填充时逐项回答)

- [ ] 评估维度:每个模块按「职责清晰 / 耦合度 / 测试覆盖 / 技术债」打分(1-5)
- [ ] 高风险区:哪些模块改动最危险(如 contextCompactor 的字节稳定性)、为什么
- [ ] 已知问题清单:从 deep-dive 中收集的坑与遗留问题,按优先级排序
- [ ] 清理建议:每个问题的修复方向与工作量

## 产出形式

逐模块评分表 + 待办清单(含优先级 / 影响模块 / 工作量)。
