## 一、问题(用户可感知)

多轮对话后回答「含混模糊」,压缩后模型不再握有「当前目标是什么」;
已写入本地的记忆/清单,模型在需要时并未真正回读。

## 二、根因(源码已核对,共 5 条)

| # | 根因 | 位置 |
|---|---|---|
| 1 | 裁剪按 seq 降序删行 → 优先删「最新」需求/结论,古老内容反而保留;**目标恰在最易被丢的位置** | `contextManager.trimTracksToBudget` |
| 2 | 任务锚只处理「尾部是干净 user 文本」→ **工具执行轮里根本看不到计划** | `agentLoop.injectTodoIntoMessages` |
| 3 | 压缩块固定置于 `messages[0]`,离当前回合最远(lost-in-the-middle);回查提示只有块尾一行、信号弱 | `contextManager` / `contextCompactor` |
| 4 | 记忆索引与 system 段在会话开始时冻结,会话内新增记忆不刷新索引 | `systemPrompt` / `chatViewProvider` |
| 5 | 省略标记的引导文案**纯文件导向**(「请用 Read 重新读取」),而 MemoryWrite/TodoWrite 场景应引导 MemoryRead/清单 → 把模型引向错误的回读工具 | `toolUsePolicy.transientSummary` |
