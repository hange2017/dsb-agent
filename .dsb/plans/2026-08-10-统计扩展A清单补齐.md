# 统计扩展 A 清单补齐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use dsb-skills:subagent-driven-development (recommended) or dsb-skills:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐统计扩展 A 清单剩余 6 项(A3 雪崩量化 / A4 小时汇总 / A5 QA / A6 轮次聚合 / A7 逐位置明细 / A8 preparedMs)+ 统计开关。

**Architecture:** 事件侧(src/agent/* + src/chat/*)补充打点,新增 compaction_qa 事件;聚合侧新增纯函数文件 src/stats/aggregate.ts(A3/A4/A6,零落盘);统计开关 dsbAgent.stats.{enabled,detailLevel} 控制落盘粒度。QA 的 LLM token 独立记账,对账时扣除。

**Tech Stack:** TypeScript + Vitest(引擎层不依赖 vscode 模块)。

## Global Constraints

- 引擎层代码(src/ 下非 webview 部分)不直接依赖 `vscode` 模块。
- 所有新增事件字段**可选**,向后兼容旧 JSONL 数据。
- QA 的 LLM 调用**不走 onProviderRound**,不污染 provider_round 统计。
- QA token 只记在 compaction_qa 事件自身(qaInputTokens/qaOutputTokens)。
- 提交信息用中文,格式 `feat(stats): ...` / `test(stats): ...`。
- 每次实现必须 `npx tsc --noEmit` + `npx vitest run` 全绿 + `node esbuild.mjs` 构建通过。

### Task 3: 聚合侧 A3/A4/A6(Agent C)

**Files:**
- Create: `src/stats/aggregate.ts`
- Create: `tests/aggregate.test.ts`

**Interfaces:**
- Consumes: `StatsStore` 的事件数组(StatsEvent[]),`CompactionRecord`,`provider_round` 事件 data(含 phase/roundMs/cacheReadTokens/inputTokens/outputTokens)
- Produces(全部导出为纯函数):
  - `analyzeCacheAfterCompact(events: StatsEvent[], opts?: { baselineRounds?: number; recoveryStreak?: number }) => CacheAfterCompactReport`
  - `hourlyCostSummary(events: StatsEvent[], prices?: { hitPerM?: number; missPerM?: number; outputPerM?: number }) => HourlyCostReport`
  - `sessionRoundAgg(events: StatsEvent[]) => SessionRoundAggReport`

**步骤:**

- [ ] **Step 1: 定义类型**
  - `CacheAfterCompactReport`: `{ compactions: Array<{ startedAt; beforeMissRate; firstMissRate; extraMissTokens; recoveryRounds }>; totalExtraMissTokens; avgRecoveryRounds }`
  - `HourlyCostReport`: `{ hours: Array<{ hour; rounds; compactions; inputHit; inputMiss; output; costHit; costMiss; costOutput; costTotal; qaInput; qaOutput; qaCost; realCost }> }`
  - `SessionRoundAggReport`: `{ rounds: Array<{ roundIndex; ok; roundsSinceCompaction; windowTokens }>; agg: Array<{ windowTokens; compressCount; roundsAnalyzed; successRate }> }`

- [ ] **Step 2: analyzeCacheAfterCompact 实现**
  - 从 events 中筛 `compaction`(取 startedAt 最早的流程事件,或按 startedAt 分组取 max)与 `provider_round`(phase=chat)。
  - 对每次压缩:基线 = 压缩前 baselineRounds(默认 5)轮 miss 率中位数;miss 率 = (inputTokens - cacheReadTokens) / inputTokens。
  - 压缩后每轮:missRate 高于基线 → extraMissTokens += (missRate - baseline) × inputTokens;连续 recoveryStreak(默认 3)轮低于基线 → 恢复。
  - firstMissRate = 压缩后第 1 轮 miss 率。

- [ ] **Step 3: hourlyCostSummary 实现**
  - 按本地小时(用事件 t 构造 Date,hour = `${y}-${m}-${d}T${hh}:00`)分组。
  - provider_round 每轮:inputHit += cacheReadTokens;inputMiss += inputTokens - cacheReadTokens;output += outputTokens。
  - compaction 计数;compaction_qa 事件:qaInput += qaInputTokens;qaOutput += qaOutputTokens。
  - 成本:costHit = inputHit × hitPerM/1e6;costMiss = inputMiss × missPerM/1e6;costOutput = output × outputPerM/1e6;qaCost = (qaInput×missPerM + qaOutput×outputPerM)/1e6(用未命中单价)。realCost = costTotal - qaCost。
  - 默认单价:hit ¥0.02/M, miss ¥1/M, output ¥2/M。

- [ ] **Step 4: sessionRoundAgg 实现**
  - 轮次边界:phase=chat 的 provider_round 每轮 roundIndex 递增;error 事件(与 provider_round 时间相邻的 `{type:"error"}` 或 onEvent error)标记该轮 ok=false。
  - 注意:引擎错误事件是 `AgentEvent["error"]`,但事件日志里可能没有直接 error 事件——用 provider_round 的 phase=chat 按时间序分组,同 sessionId 内轮次级。error 判定:若该轮 time 窗口内存在 message_sent/tool error 信号,简化处理为:无 provider_round 输出但会话结束 → 该轮 ok=false(若数据中无 error 事件,则按「轮间间隔 > 5min 且无后续轮」判为中断轮)。
  - 为可测试性:允许 `errorRounds?: Set<number>` 由调用方传入(测试直接构造)。
  - roundsSinceCompaction:距离上次 compaction(按 startedAt)的轮数;-1 表示压缩前。
  - windowTokens:该轮 provider_round 附近的配置窗口(若无记录,用 0 表示未知)。
  - agg:按 windowTokens 分组,统计 compressCount(该窗口下会话压缩次数)、roundsAnalyzed、successRate。

- [ ] **Step 5: 测试(重点构造样例数据)**
  - A3:构造 10 轮 provider_round(压缩前 5 轮 miss 率 5%,压缩后第 1 轮 90%,逐步回落)→ 断言 firstMissRate≈0.9、extraMissTokens>0、recoveryRounds>0。
  - A4:构造同一小时 3 轮 + 1 次 compaction + 1 次 compaction_qa → 断言 qaInput/qaCost 单列、realCost = costTotal - qaCost。
  - A6:构造 2 个 sessionId 各若干轮,带 errorRounds → 断言 successRate 计算正确。
  - 样例事件用 `{ t, type, data }` 字面量构造,不依赖真实文件。

- [ ] **Step 6: 验证 + 提交**
  - `npx tsc --noEmit` + `npx vitest run tests/aggregate.test.ts` 全绿。
  - `git commit -m "feat(stats): A3/A4/A6 聚合纯函数(雪崩量化/小时成本/轮次成功率)"`
